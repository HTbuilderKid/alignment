# Alignment engine

Pure Step 6 domain functions for context freshness, non-overlapping historical intervals, and explainable assessments. Inputs include explicit time and evidence; outputs are domain results or interval-replacement plans. The engine has no UI, persistence, network, or Android dependency.

See [Step 6](../../docs/STEP_6.md) for invariants, application commands, migration details, and validation commands. Shared contracts live in `@alignment/types`.
